# Encrypted Source

This directory contains the source files for **PORTFOLIO003 — World Record Poetry Book Tracker** in an encrypted, password-protected archive.

The archive contains the project files for the Flask/Python web application, including the application source code, database components, HTML templates, CSS, tests, and related documentation.

## Project

**PORTFOLIO003 — World Record Poetry Book Tracker**

* **Framework:** Flask
* **Language:** Python
* **Database:** SQLite
* **Frontend:** HTML / CSS
* **Development tool:** Google Antigravity

## Archive

The project source has been packaged as a **ZIP archive and encrypted/password-protected** before being uploaded to this repository.

The archive represents the project files generated and tested during the development of the application.

## Access

The archive is intentionally password-protected.

**The password is not stored in this repository.**

If you have been provided with the password, use it to extract the archive locally.
