# PORTFOLIO003 — World Record Poetry Book Tracker

A simple Flask/Python web application for tracking a collection of poetry books written and published as part of a world-record achievement.

## Purpose

The **World Record Poetry Book Tracker** provides a simple way to maintain a chronological record of poetry books.

The application allows the user to enter books individually and record:

* Book title
* Publication year

Books can subsequently be edited or deleted.

The main dashboard displays the collection of books entered and the total number of books recorded.

## Core Functionality

The application provides functionality to:

* **Add** a poetry book
* **View** all recorded books
* **Edit** a book title
* **Edit** a publication year
* **Delete** a book
* **Display the total number of books**

The application is deliberately focused on this single purpose rather than attempting to provide a comprehensive publishing or book-management system.
